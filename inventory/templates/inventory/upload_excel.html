Bulk upload — {{ current_organization.name }}

Upload a .xlsx spreadsheet to add or update many items at once. A row whose SKU doesn't exist yet becomes a new item; a row whose SKU already exists updates that item's details and adds the row's quantity to its current stock (treated as a new delivery, not a correction). Every row is logged in the item's activity history, same as any other stock change.

Expected columns (any order — only SKU and Name are required):

SKU, Name, Description, Track Quantity, Unit, Quantity, Location, Location Description, Reorder Level, Allow Take, Allow Borrow

"Location" and "Location Description" are plain text set on that row's item alone — not a shared list, so different items can use the same location name independently. A blank Location cell on a re-upload leaves the item's existing location untouched rather than clearing it.

Set "Track Quantity" to No for bulk items you don't want to count individually (e.g. a pile of sand) — Unit, Quantity, Reorder Level, Allow Take, and Allow Borrow are all ignored for that row; only the location is used.
